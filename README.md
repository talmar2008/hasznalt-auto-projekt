Használt autók nyilvántartása

A projekt célja
A projekt egy használt autókat nyilvántartó program elkészítése C# nyelven.

Funkciók
- Autók adatainak beolvasása TXT-fájlból
- Autók adatainak listázása
- Legolcsóbb és legdrágább autó megkeresése
- Legkevesebb kilométert futott autó megkeresése
- Átlagár kiszámítása
- Benzines autók listázása

Használt technológiák
- C#
- TXT-fájl
- MySQL
